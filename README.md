Side B

-->Descripción
Side B es un proyecto web desarrollado en HTML y CSS que funciona como una red social enfocada en la música. Su objetivo es crear un espacio donde los usuarios puedan compartir sus opiniones, reseñas y gustos musicales, además de descubrir nueva música a través de las publicaciones de la comunidad.

-->Principales características
1. Inicio: Muestra álbumes y contenido musical destacado o trending.
2. Acerca de: Presenta información sobre el propósito y concepto de Side B.
3. Reseñas: Permite visualizar opiniones y reseñas musicales compartidas por la comunidad.
4. Crear publicación: Cuenta con una sección para crear y compartir publicaciones relacionadas con la música.
5. Perfil: Incluye una sección dedicada al perfil del usuario.
6. Navegación: Cuenta con una barra de navegación que permite acceder fácilmente a las diferentes secciones del sitio.

-->Tecnologías utilizadas
1. HTML5

2. CSS3

3. JavaScript
